# Переменные окружения

Вся конфигурация берётся из файла `.env` (или реальных переменных окружения),
читаемого при запуске. Пояснения и эффекты приведены в разделе
[Конфигурация](../getting-started/configuration.md); это краткая таблица.

!!! warning
    Значения задаются в виде простого `KEY=value`. Символы `<`, `>` или пробелы
    без кавычек ломают парсер dotenv и приводят к ошибке `required env var ... not set` при запуске.

## База данных

| Переменная | Обязательна | По умолчанию | Описание |
|----------|----------|---------|-------------|
| `DATABASE_URL` | да | — | DSN для PostgreSQL, например `postgres://ecb:pass@127.0.0.1:5432/emergency_callback?sslmode=disable`. |
| `DB_POOL_MAX_CONNS` | нет | `100` | Максимум соединений в пуле. |
| `DB_POOL_MIN_CONNS` | нет | `10` | Минимум соединений в пуле. |

## HTTP-сервер

| Переменная | Обязательна | По умолчанию | Описание |
|----------|----------|---------|-------------|
| `HTTP_ADDR` | нет | `:8000` | Адрес прослушивания. За прокси используйте `127.0.0.1:8000`. |
| `SITE_DOMAIN` | да | — | Публичный базовый URL; используется для построения ссылок голосования в SMS. Без завершающего слэша. |
| `SESSION_SECRET` | да | — | Ключ шифрования cookie сессии (32+ байт). Его изменение разлогинивает всех. |
| `CSRF_KEY` | да | — | Ключ CSRF; должен быть **ровно 32 байта** (`openssl rand -base64 24`). |
| `COOKIE_SECURE` | нет | `false` | `true` за HTTPS-прокси: cookie сессии передаётся только по TLS. |

## Телефония

| Переменная | Обязательна | По умолчанию | Описание |
|----------|----------|---------|-------------|
| `TELEPHONY_BACKEND` | нет | `ami` | `ami` (классический, dialplan на АТС) или `ari` (Stasis, dialplan не нужен). |

## Asterisk AMI (обязательны при `TELEPHONY_BACKEND=ami`)

| Переменная | Обязательна | По умолчанию | Описание |
|----------|----------|---------|-------------|
| `AMI_HOST` | для ami | — | Хост AMI (часто `127.0.0.1`). |
| `AMI_PORT` | нет | `5038` | Порт AMI. |
| `AMI_USERNAME` | для ami | — | Пользователь AMI (должен существовать в Asterisk). |
| `AMI_SECRET` | для ami | — | Секрет AMI (должен совпадать с Asterisk). |
| `AMI_CALLER_ID` | нет | — | Номер Caller ID, отображаемый при исходящих вызовах. Только голый номер/строка. |
| `AMI_OPERATOR_QUEUE` | нет | `777` | Назначение оператора для ARI-бэкенда (extension/queue в `from-internal`). В AMI-режиме цель задаётся в dialplan. |
| `AMI_CALL_TIMEOUT` | нет | `60` | Секунды до отказа от вызова (общий для обоих бэкендов). |
| `AMI_RATING_RETRY_LIMIT` | нет | `3` | Допустимое число неверных нажатий клавиш до отказа (общий). |
| `AMI_RATING_TIMEOUT` | нет | `10` | ARI: секунды тишины после подсказки до повтора/завершения. |

## Asterisk ARI (обязательны при `TELEPHONY_BACKEND=ari`)

| Переменная | Обязательна | По умолчанию | Описание |
|----------|----------|---------|-------------|
| `ARI_URL` | для ari | — | Например `http://<freepbx-ip>:8088/ari`. |
| `ARI_USERNAME` | для ari | — | Пользователь ARI (FreePBX: Settings → Asterisk REST Interface Users). |
| `ARI_PASSWORD` | для ari | — | Пароль ARI. |

## Аудио

| Переменная | Обязательна | По умолчанию | Описание |
|----------|----------|---------|-------------|
| `AUDIO_DIR` | нет | `audios` | Каталог WAV-подсказок на сервере приложения. |
| `AUDIO_MEDIA_BASE_URL` | нет | — | Если задан и на АТС загружен `res_http_media_cache`, ARI-бэкенд проигрывает подсказки по HTTP с этого базового URL (обычно = `SITE_DOMAIN`); файлы на АТС не нужны. |
| `PBX_SSH_HOST` | нет | — | SSH-хост АТС для автопуша аудио при загрузке в админке (режим `sound:`). |
| `PBX_SSH_USER` | нет | — | SSH-пользователь. |
| `PBX_SSH_PASSWORD` / `PBX_SSH_KEY` | нет | — | Пароль или путь к приватному ключу. |
| `PBX_SOUNDS_DIR` | нет | `/var/lib/asterisk/sounds/en` | Каталог звуков Asterisk на АТС. |

## Eskiz SMS

| Переменная | Обязательна | По умолчанию | Описание |
|----------|----------|---------|-------------|
| `ESKIZ_EMAIL` | для SMS | — | Email учётной записи Eskiz. |
| `ESKIZ_PASSWORD` | для SMS | — | Пароль учётной записи Eskiz. |
| `ESKIZ_BASE_URL` | нет | `https://notify.eskiz.uz/api` | Базовый URL API. |
| `ESKIZ_DRY_RUN` | нет | `false` | При `true` SMS логируются вместо отправки. |

|----------|----------|---------|-------------|

## На этапе сборки / особые

| Переменная | Где | Описание |
|----------|-------|-------------|
| `MIGRATIONS_DIR` | подкоманда `migrate` | Переопределяет каталог миграций (по умолчанию `migrations`). |
| `ENABLE_PDF_EXPORT` | сборка документации | Установите в `1`, чтобы также рендерить сайт документации в PDF (`mkdocs build`). |
